# Pollinations.AI 图像生成工具

## 简介 (Introduction)

Pollinations.AI 是一个开源的生成式 AI 平台，提供免费的文本、图像和音频生成 API，无需注册或 API 密钥。这使其成为教育环境中理想的 AI 工具，特别是对于初学者和学生。

Pollinations.AI is an open-source generative AI platform that provides free text, image, and audio generation APIs without requiring registration or API keys. This makes it an ideal AI tool for educational environments, especially for beginners and students.

## 主要特点 (Key Features)

- **完全免费使用** - 无需付费或信用卡
- **无需注册** - 无需账户或 API 密钥
- **注重隐私** - 不存储用户数据
- **简单的 URL 端点** - 通过简单的 URL 请求生成内容
- **支持多种生成类型** - 文本、图像和音频生成
- **OpenAI 兼容接口** - 与流行的 AI 工具兼容
- **React 钩子** - 用于简单集成的 React 组件

- **Completely free to use** - No payment or credit card required
- **No registration needed** - No account or API keys required

- **Simple URL endpoints** - Generate content via simple URL requests
- **Multiple generation types** - Text, image, and audio generation
- **OpenAI-compatible interfaces** - Compatible with popular AI tools
- **React hooks** - React components for simple integration

## 使用示例 (Usage Examples)

### 图像生成 (Image Generation)

通过简单的 URL 请求生成图像：

Generate images with a simple URL request:

```
https://image.pollinations.ai/prompt/A%20beautiful%20mountain%20landscape%20with%20sunset
```

### 文本生成 (Text Generation)

使用文本生成 API 创建文本：

Create text using the text generation API:

```
https://text.pollinations.ai/v1/chat/completions
```

### 音频生成 (Audio Generation)

将文本转换为语音：

Convert text to speech:

```
https://text.pollinations.ai/Welcome%20to%20Pollinations?model=openai-audio&voice=nova
```
